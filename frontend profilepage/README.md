# GlowinWebapp
A responsive e-commerce website frontend built using HTML, CSS, and JavaScript, featuring product listings, product details, cart UI, and a modern user-friendly design.


E-Commerce Frontend Website

This project is a frontend-only e-commerce web application developed to practice and demonstrate modern UI development skills. The application focuses on user experience, responsive layout, and clean design, simulating a real-world online shopping platform.

The project includes essential e-commerce features such as product listing pages, product detail views, shopping cart UI, and checkout flow (UI only). It is built without any backend integration, making it ideal for frontend learning, UI/UX practice, and portfolio showcase.
